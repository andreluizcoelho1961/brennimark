The **brand's typography** is a sheet: for each use of text, which font the manual says to use. It
feeds **Grids** (the document's text styles), **Kit** (the email signature's font)
and **Vini** (who answers about typography citing the sheet).

It lives under **Administration**, in the left menu, and is for whoever edits the brand.

## The six uses

The sheet has one row per use:

| Use | What it is for |
|---|---|
| **Title** | the titles |
| **Subtitle** | the subtitles |
| **Text** | running text |
| **Caption** | captions and notes |
| **Highlight** | callouts and highlights |
| **Support** | support text and footers |

## Fill in the sheet

Click **Add font** and choose the use. Fill in:

- **Family:** the font's name. It is required.
- **Style:** Regular, Bold and so on.
- **PostScript name:** the font's exact name, without spaces. It is what InDesign looks for.
- **Substitute font:** the system font the manual allows where the brand's doesn't run (for example,
  in an email).
- **Size**, **leading** and **tracking**, if the manual defines them. They are optional.
- **As the manual says:** the manual's sentence, for whoever checks it later.

Click **Save font**. It comes in as a **draft**.

## Read from the manual

Instead of typing, click **Read from the manual**. The AI reads the typography pages and fills in the uses that
are missing. They come in as a **draft**, marked **read by the AI**, and **never replace a font that is already
on the sheet**. Check each name against the page before approving. The manual needs to be prepared for
Vini (see [The manual as a PDF](/ajuda/manual-em-pdf)).

## Approve

A draft doesn't count as a rule. Whoever can approve clicks **Approve**, and the row becomes **Approved**. Only the
approved font goes to Grids, to Kit and to what Vini states without reservation. **Editing** an
approved font returns it to draft until it is approved again. **Remove** only deletes what is still
a draft.

## And the font file?

The sheet keeps **the name and the usage rules**, not the file. Without an approved font, Grids builds the
text styles at the grid's size and leading, with InDesign's default font.

Uploading the **font file** to Materials first requires the **signed license agreement** from whoever
signs up for Brennimark: responsibility for the license is theirs. While the agreement isn't signed, the
Materials screen says the font file isn't accepted yet. A font never goes by delivery link.
See the [font license](/licenca-de-fontes).
