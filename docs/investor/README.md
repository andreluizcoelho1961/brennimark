# Materiais de pré-investimento

**Versão do conjunto:** 1.1 · **data de referência:** 27 de agosto de 2026

Esta pasta pertence à startup do aplicativo de gestão de marcas, não ao projeto Guitar
Garage. O nome Brandville aparece nos arquivos existentes apenas como codinome provisório.

A Guitar Garage pode ser citada como caso demonstrativo externo. Ela não deve ser usada como
evidência de product-market fit, repetibilidade técnica, retenção ou economia do canal.

## Fontes oficiais

O conjunto usa duas fontes complementares, que devem receber a mesma versão e data:

- o arquivo Markdown é a fonte oficial da narrativa, recomendações e ressalvas;
- o arquivo JSON é a fonte oficial dos números, fórmulas, tabelas e metadados;
- o arquivo HTML é uma saída gerada e não deve ser editado manualmente.

Uma alteração numérica só está concluída quando aparece no JSON e na narrativa que a
interpreta. Uma alteração narrativa que afete premissas, gates ou definições também deve ser
refletida nos metadados do JSON. O HTML deve ser regenerado por último a partir do JSON
validado.

## Arquivos principais

- `platform-preinvestment-study.md` — estudo final completo em Markdown, para edição,
  versionamento e reaproveitamento em apresentações;
- `platform-preinvestment-report.html` — relatório portátil para leitura;
- `platform-preinvestment-artifact.json` — fonte estruturada e auditável do relatório.

## Guia de entrada no mercado

- `startup-commercial-validation-guide.md` — guia institucional de entrada no mercado e
  validação comercial;
- `startup-commercial-validation-guide-artifact.json` — fonte estruturada do guia;
- `startup-commercial-validation-guide.html` — versão portátil para leitura e compartilhamento.
